# Day 1: IAM basics

I think of a user as a badge that shows who I am. A policy says which doors the badge opens. A role is like a uniform I put on for a while.

A policy is built from Effect, Action and Resource. Everything is denied unless a policy allows it.

I made an IAM user for my daily work and turned on MFA, so now I don't use the root account anymore. I also set a billing alarm that goes off above 1 cent, so I don't get a surprise bill.
